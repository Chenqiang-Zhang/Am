# 推荐算法横向对比与进化报告

## 实验设置

- 评估用户数：1000
- 商品数：1728
- 留出方式：每个用户最新一条 4 星及以上评分作为未来目标商品。
- 指标：HR@K、NDCG@K、MRR@K、Catalog Coverage@10、Avg Rating@10、Diversity@10。
- 本轮说明：第四轮迭代：发现 RRF 融合会稀释 Top10 相关性后，改为 Transition-first Hybrid v4；Transition-CF 保持前排，Recent Item-CF/User-CF/KG/Popularity 只在转移证据不足时补召回。

## 客观判断

- 当前最优方法按 NDCG@50 判断为：`hybrid_v4`。
- 如果 `kg_meta_path_v1` 低于 Item-CF/User-CF，这是合理现象：KG 属性路径更擅长解释和语义泛化，不一定擅长精确预测未来同一个 ASIN。
- 如果 Transition-CF / Recent Item-CF 高于单一 KG 方法，说明应把近期行为和序列转移作为线上主排序信号，而不是只依赖属性元路径。

## 结论与改进方向

- 保留 KG 元路径作为解释层和语义召回层。
- 引入 Transition-CF / Recent Item-CF / User-CF 作为行为协同排序信号，提高 exact-ASIN 离线预测能力。
- 继续增加 VIEWED/点击数据后，可重新评估在线行为对排序的贡献。
